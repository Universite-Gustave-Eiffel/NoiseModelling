Terts to octave
===============

Convert emission table from terts to octave

Overview
--------

Create an emission table with octave frequency bands from the terts bands
This script converts an existing emission table with terts frequency bands to octave bands. This can be helpful for railway calculations where the source emission should be calculated in third octave bands and all the rest in regular octave bands.

Arguments
---------

Mandatory inputs
~~~~~~~~~~~~~~~~

``tableName`` — *Table name*
   Name of the table to convert from terts to octaves bands.
   The table must contain (* mandatory):
   
   *   PK * : an identifier. It shall be a primary key (INTEGER, PRIMARY KEY)
   
   *   PK_SECTION * : an identifier referencing the railway section
   
   *   THE_GEOM * : the 3D geometry of the sources (POINT, MULTIPOINT, LINESTRING, MULTILINESTRING). According to CNOSSOS-EU, you need to set a height of 0.05 m for a road traffic emission
   
   *   HZD50, HZD63, HZD80, HZD100, ..., HZD8000, HZD10000 * : 24 columns giving the day emission sound level for each octave band (FLOAT)
   
   *   HZE * : 24 columns giving the evening emission sound level for each octave band (FLOAT)
   
   *   HZN * : 24 columns giving the night emission sound level for each octave band (FLOAT)
   
   *   DIR_ID * : identifier of the directivity sphere from tableSourceDirectivity parameter or train directivity if not provided -> OMNIDIRECTIONAL(0), ROLLING(1), TRACTIONA(2), TRACTIONB(3), AERODYNAMICA(4), AERODYNAMICB(5), BRIDGE(6) (INTEGER)
   
   *   HRAIL * : rail platform height. Used in body barrier calculation for train noise propagation. Generated by Railway_Emission_from_Traffic block.
   
   *   CREF * : Cref (vehicle body reflection coefficient). 0 = no body barrier (road sources or open freight), 1 = fully reflecting body. Used in body barrier calculation.
   
   *  Mb> GS *: ground factor between rails.
   
   Any other columns (even YAW, PITCH, or ROLL) are **not** copied. This table can be generated from the Block "Railway_Emission_from_Traffic".

   Type: ``String``

Output
------

``outputTable`` — *Name of the created table*
   Name of the created table

   Type: ``String``
